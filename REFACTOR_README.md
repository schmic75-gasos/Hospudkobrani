# Hospudkobrani — refactor branch

Tato větev bude obsahovat postupné rozdělení monolitického App.js do modulů.

Struktura:
- /screens — top-level obrazovky
- /components — znovupoužitelné komponenty
- /api — API helpery
- /utils — pomocné funkce
- /theme — barvy, styly, mapLayerStyles
- /constants — statické konstanty (API URL, tokeny)

Poznámka: Toto je počáteční commit se strukturou. Následující kroky provádějí přesuny a úpravy kódu.
